Índice de busca do agente

A base é consultada por busca híbrida (vetor + texto). Gravar um trecho já tenta sincronizar o índice.

A API administrativa não expõe o estado do índice (não há rota de status nem contagem de trechos indexados). Ele aparece aqui depois de uma gravação ou de uma reindexação; para o estado real a qualquer momento, use poph kb status --offline na instância.

A reindexação é síncrona: a tela espera a resposta do servidor, que pode demorar (a primeira carrega o modelo de embedding). Não feche a aba durante o processo.
