Gerencia agentes: identidade, modelo, parâmetros, handoff e categorias

Usage: poph agent [OPTIONS] <COMMAND>

Commands:
  create  Cria o agente na org
  list    Lista os agentes da org (paginado por id)
  show    Mostra um agente, as categorias e o texto composto das instruções
  update  Altera um agente com `If-Match`; também define as categorias de produto
  delete  Exclui um agente (instruções, vínculos e conversas saem junto)
  help    Print this message or the help of the given subcommand(s)

Options:
      --config <ARQUIVO>  Arquivo de configuração TOML. Sem ele, usa POPH_CONFIG ou ./poph.toml, se existir
      --org <ORG>         Org do contexto (id UUID v7 ou slug). Obrigatória nos comandos que mexem em dados de org
      --offline           Opera direto no banco, sem servidor. Obrigatório em `org`, `token`, `category`, `department`, `kb` e `file` enquanto o modo com servidor não existe
  -h, --help              Print help
