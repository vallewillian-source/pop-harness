Retenção do histórico: apaga o que venceu (`run`) e mostra a configuração (`show`)

Usage: poph retention [OPTIONS] <COMMAND>

Commands:
  run   Apaga o histórico vencido. Use `--dry-run` para ver o que sairia, sem apagar
  show  Mostra quantos dias de histórico cada org guarda (`--org` para uma só)
  help  Print this message or the help of the given subcommand(s)

Options:
      --config <ARQUIVO>  Arquivo de configuração TOML. Sem ele, usa POPH_CONFIG ou ./poph.toml, se existir
      --org <ORG>         Org do contexto (id UUID v7 ou slug). Obrigatória nos comandos que mexem em dados de org
      --offline           Opera direto no banco, sem servidor. Obrigatório em `org`, `token`, `category`, `department`, `kb` e `file` enquanto o modo com servidor não existe
  -h, --help              Print help
