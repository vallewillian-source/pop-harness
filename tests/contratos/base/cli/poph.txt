POP Harness: motor de agentes multi-tenant

Usage: poph [OPTIONS] [COMMAND]

Commands:
  doctor        Confere o ambiente: configuração, pasta de dados, bancos e variáveis obrigatórias
  migrate       Cria ou atualiza os bancos (`harness.db` e `rag.db`). Rode com o servidor parado
  model         Gerencia o modelo de embedding (`poph model install` baixa e confere o modelo)
  agent         Gerencia agentes: identidade, modelo, parâmetros, handoff e categorias
  instructions  Gerencia as instruções estruturadas e o texto composto do agente
  org           Gerencia as orgs (tenants): criar, listar, mostrar, alterar e excluir
  token         Gerencia os tokens de administração de uma org (`--org`)
  category      Gerencia as categorias de produto de uma org (`--org`)
  department    Gerencia os departamentos de uma org (`--org`)
  kb            Base de conhecimento: grupos, itens, vínculo com agentes e índice (HR-17)
  rag           Índice da busca semântica: `poph rag reindex` (mesmo comando do `poph kb reindex`)
  product       Produtos do catálogo: criar, listar, alterar, excluir e reindexar (HR-18)
  file          Biblioteca de arquivos do agente: enviar, listar, mostrar e excluir (HR-24)
  chat          Conversa com um agente pelo terminal (streaming; Ctrl-C cancela o turno)
  jev           Jev (decisões rápidas): `eval` mede um gate sobre um conjunto rotulado (HR-28)
  flow          Fluxos da org: validar, publicar, listar, mostrar, comparar, formatar e liberar a agentes
  ficha         Fichas da org (um atendimento por Ficha): listar e mostrar, com as execuções de fluxo
  retention     Retenção do histórico: apaga o que venceu (`run`) e mostra a configuração (`show`)
  backup        Exporta uma org inteira num arquivo único e reconstrói a partir dele (HR-53)
  cluster       Roteamento entre instâncias: mostra e confere o `cluster.toml` (HR-50a)
  matrix        Módulo Matrix: registro do Application Service (`registro`) e, por org (`--offline --org`), `estado`, `ligar`, `desligar` e `espaco`
  serve         Sobe o servidor HTTP (API administrativa, `/healthz` e `/metrics`)
  openapi       Imprime o documento OpenAPI (base do cliente TypeScript do Console)
  help          Print this message or the help of the given subcommand(s)

Options:
      --config <ARQUIVO>  Arquivo de configuração TOML. Sem ele, usa POPH_CONFIG ou ./poph.toml, se existir
      --org <ORG>         Org do contexto (id UUID v7 ou slug). Obrigatória nos comandos que mexem em dados de org
      --offline           Opera direto no banco, sem servidor. Obrigatório em `org`, `token`, `category`, `department`, `kb` e `file` enquanto o modo com servidor não existe
  -h, --help              Print help
  -V, --version           Print version
