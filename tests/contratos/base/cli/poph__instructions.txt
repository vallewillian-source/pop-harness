Gerencia as instruções estruturadas e o texto composto do agente

Usage: poph instructions [OPTIONS] <COMMAND>

Commands:
  create  Grava as instruções do agente (o agente não pode ter instruções ainda)
  update  Altera as instruções existentes com `If-Match`
  show    Mostra o JSON estruturado e o texto composto
  delete  Apaga as instruções do agente
  list    Lista as instruções da org (um registro por agente que já tem instruções)
  help    Print this message or the help of the given subcommand(s)

Options:
      --config <ARQUIVO>  Arquivo de configuração TOML. Sem ele, usa POPH_CONFIG ou ./poph.toml, se existir
      --org <ORG>         Org do contexto (id UUID v7 ou slug). Obrigatória nos comandos que mexem em dados de org
      --offline           Opera direto no banco, sem servidor. Obrigatório em `org`, `token`, `category`, `department`, `kb` e `file` enquanto o modo com servidor não existe
  -h, --help              Print help
