Reconstrói a org a partir de um arquivo de `backup export`

Usage: poph backup import [OPTIONS] <ARQUIVO>

Arguments:
  <ARQUIVO>  Arquivo gerado por `poph backup export`

Options:
      --config <ARQUIVO>  Arquivo de configuração TOML. Sem ele, usa POPH_CONFIG ou ./poph.toml, se existir
      --org <ORG>         Org de destino já existente (id ou slug). Sem ele, vale a org de origem do arquivo
      --sobrescrever      Autoriza atualizar linhas que já existem no destino (padrão: a importação recusa)
      --json              Saída em JSON (formato estável)
      --offline           Opera direto no banco, sem servidor. Obrigatório em `org`, `token`, `category`, `department`, `kb` e `file` enquanto o modo com servidor não existe
  -h, --help              Print help
